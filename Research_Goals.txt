This is a file to note the current research goals and questions to be discovered through exploration of EEG this is list is not to be fully explored
but used as reasonable beginnings to find long term objectives to target to build and improve the model:
(1) What is the difference in performance of unsupervised vs supervised machine learning techniques for EEG
    - How can science based machine learning be implemented to create a more readable algorithm
(2) How does predicting the data through continuous assumption of direction to maintain the same thing until a stimuli for a different direction
    vs continuous rerunning the data to keep finding the same signal
(3) Start/stop for signal based off hardware or based off a different stimuli (looking at different frequency domain specified activity?)
(4) Model accuracy based on runtime speed or cost to decide for real time analysis what works
